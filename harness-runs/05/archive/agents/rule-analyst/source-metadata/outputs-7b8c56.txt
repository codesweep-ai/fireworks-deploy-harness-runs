+# API — public JSON readback / filter / escaping / nulls
+
+## R-API-001
+- **ID**: R-API-001
+- **Statement**: GET `/api/tasks` returns a JSON array of task rows read straight from the DB, outside the authenticated UI path (the filter exempts `/api/`). It is reachable with no session at all.
+- **Source citations**: ApiTaskServlet.java:14-17,23-49; AuthFilter.java:28
+- **Actors and preconditions**: Any client, authenticated or not.
+- **Trigger**: GET /api/tasks.
+- **Effects or refusal**: 200 application/json UTF-8 array; no mutation.
+- **Observed versus intended**: OBSERVED: unauthenticated readback. INTENDED per source comment ("public read-back ... outside the UI path"); flagged in defect ledger (D-007 context) for the verifier to confirm the exposure is acceptable.
+- **Linked EARS IDs**: S-API-001
+
+## R-API-002
+- **ID**: R-API-002
+- **Statement**: Optional `status` param filters exactly like the UI list: empty/absent -> all tasks (findAll, updated_at DESC); non-empty -> search(status,null,null); unknown status values return an empty array, HTTP 200. No other filter or sort params are honored (assignee/sort are ignored).
+- **Source citations**: ApiTaskServlet.java:24-27; TaskDao.java:22-24,40-56
+- **Actors and preconditions**: Any client.
+- **Trigger**: GET /api/tasks?status=DONE, ?status=, ?status=BOGUS, ?assignee=3&sort=title.
+- **Effects or refusal**: DONE-only array / full array / [] / full array (extra params ignored).
+- **Observed versus intended**: Observed.
+- **Linked EARS IDs**: S-API-002
+
+## R-API-003
+- **ID**: R-API-003
+- **Statement**: Each object exposes exactly id, title, status, priority, assigneeId, projectId, dueDate, updatedAt; description and the display-join names are NOT exposed; updatedAt is emitted with seconds precision.
+- **Source citations**: ApiTaskServlet.java:36-45; TaskDao.java:234-236
+- **Actors and preconditions**: Any client.
+- **Trigger**: GET /api/tasks.
+- **Effects or refusal**: Fixed field set per row; no extra fields.
+- **Observed versus intended**: Observed.
+- **Linked EARS IDs**: S-API-003
+
+## R-API-004
+- **ID**: R-API-004
+- **Statement**: NULL handling: assigneeId NULL -> JSON literal `null`; dueDate NULL -> JSON literal `null`; strings that are NULL would be escaped to "" but no exposed string column is nullable in practice (title/status/priority/updatedAt are NOT NULL).
+- **Source citations**: ApiTaskServlet.java:41,43; esc() 51-54; schema.sql:30-39
+- **Actors and preconditions**: Any client; a task with unassigned/no-due-date (seed task 4).
+- **Trigger**: GET /api/tasks.
+- **Effects or refusal**: `"assigneeId":null,"dueDate":null` for task 4.
+- **Observed versus intended**: Observed.
+- **Linked EARS IDs**: S-API-004
+
+## R-API-005
+- **ID**: R-API-005
+- **Statement**: String escaping is minimal hand-rolled `esc()`: only backslash and double-quote are escaped. Control characters (notably newline) and HTML-significant characters pass through raw, so a title containing a newline produces invalid JSON; `<`/`>` are not escaped either.
+- **Source citations**: ApiTaskServlet.java:51-54 (`.replace("\\","\\\\").replace("\"","\\\"")`)
+- **Actors and preconditions**: Any client; a task whose title (or other exposed string) contains `\n`, tab, or `<` — achievable through the form POST because the servlet does not restrict content (TaskFormServlet.java:41-48).
+- **Trigger**: POST /tasks/form with title containing a newline, then GET /api/tasks.
+- **Effects or refusal**: Raw newline inside a JSON string token -> response is not parseable JSON (defect candidate D-003/escaping gap). Quote and backslash round-trip correctly.
+- **Observed versus intended**: OBSERVED: quote/backslash safe, control chars/HTML not. INTENDED: spec-level JSON correctness. Defect candidate — reproducible case in findings/ledger.json.
+- **Linked EARS IDs**: S-API-005
+
+## R-API-006
+- **ID**: R-API-006
+- **Statement**: `/api/tasks` accepts GET only: the servlet overrides `doGet` exclusively, so any other method (e.g. POST) falls through to the HttpServlet default and is refused with HTTP 405 Method Not Allowed; no state change.
+- **Source citations**: ApiTaskServlet.java:18-23 (only doGet overridden); javax.servlet.http.HttpServlet default method handling; web.xml servlet-mapping apiTasks -> /api/tasks
+- **Actors and preconditions**: Any client, authenticated or not (the filter exempts /api/).
+- **Trigger**: POST (or other non-GET method) /api/tasks.
+- **Effects or refusal**: HTTP 405 Method Not Allowed; no DB write.
+- **Observed versus intended**: Observed (executed engineer evidence). Read-only API by design per source comment.
+- **Linked EARS IDs**: S-API-008

+# AUTH — authentication / session / logout / access exemptions
+
+## R-AUTH-001
+- **ID**: R-AUTH-001
+- **Statement**: Every request passes through AuthFilter (mapped to `/*`); requests to exactly `/login`, anything under `/api/`, or ending `.css` bypass the session check entirely.

+- **Observed versus intended**: Observed. `/api/*` exemption makes the whole task readback public — noted as intended-by-comment (ApiTaskServlet.java:14-17) but security-relevant.
